# Prompts shown in the film

- **B00 (illustrative reconstruction, labelled):** "Please use Walker to convert my game design document about
  Vidiyum Mun, … into two shaders I write myself: a glow on Hari's phone status bar while the night is being skipped, and a
  textured marble shader for the pool deck with a dry and a wet material. Add a hint experiment and headless tests."
  It is not a transcript; the real prompts are `prompts/a5/prompt-1.txt`, `prompt-2.txt`, `prompt-3.txt`.
- **B21 (Your Turn):** "I wrote a canvas_item shader with one uniform for a state in my game. Write a driver that sets it
  from that state by delta, and a headless test that asserts the shader's uniform list, not a set-then-get round trip.
  I've predicted one pixel at 0, 0.5 and 1."
